## 🔍 Project Overview
This project analyzes Superstore sales data to uncover insights about sales, profit, discount impact, shipping performance, and regional trends using Power BI and SQL.

The goal is to transform raw transactional data into interactive dashboards and business insights for decision-making.

---

## 🛠 Tools & Technologies
- Power BI
- SQL Server (T-SQL)
- Data Cleaning & Transformation
- Business Intelligence
- Excel / CSV

---

## 📈 Dashboard Insights
- Profit Margin % and Total Profit by Discount
- Average Shipping Days by Region
- Total Profit and Sales by Segment
- Total Sales by Year Trend
- Geographical Sales Performance (Map View)

---

## 📂 Files Included
- `Superstore_Sales_Analysis.pbix` → Power BI dashboard
- `Superstore_Sales_Analysis.pdf` → Report export
- `*.sql` → SQL analysis queries
